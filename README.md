Data Preprocessing, Cleaning, and Visualization of Fast Food Restaurant Sales

**Source:** Kaggle  
**File:** Balaji Fast Food Sales.csv

## 🎯 Objective
The objective of this project is to analyze fast food restaurant sales data by:
- Inspecting and understanding the dataset
- Cleaning missing and duplicate values
- Applying numerical statistics
- Visualizing sales patterns using graphs
- Drawing meaningful business insights

---

## 🧰 Libraries Used
- NumPy
- Pandas
- Matplotlib

---

## 🔍 Data Inspection
- Head & Tail of dataset
- Dataset information
- Shape (rows & columns)
- Column names
- Data types
- Index-based and label-based selection
- Frequency distribution using `value_counts()`

---

## 🧹 Data Cleaning
- Missing values check
- Removing null values
- Filling missing values using interpolation
- Duplicate record detection and removal

---

## 📊 Numerical Analysis
- Mean
- Median
- Standard Deviation
- Descriptive statistics

---

## 📈 Data Visualization
### Graphs Included:
- Line Graphs (Order ID vs Sales, Quantity, Price)
- Multiple Line Graphs
- Bar Charts
- Histograms
- Pie Charts
- Scatter Plot

---

## 📌 Key Insights
- Panipuri, Vadapav, and Frankie are the most sold items
- Higher sales observed during Afternoon and Night
- Strong relationship between quantity sold and transaction amount
- Popular items generate maximum revenue

---

## ✅ Conclusion
This analysis helps restaurant management to:
- Optimize inventory
- Improve staffing schedules
- Focus on high-demand items
- Increase revenue through data-driven decisions
